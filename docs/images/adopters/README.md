# Adopters images

When adding an adopter to the project README, add its image here to be referenced. For consistency, images should be:

- SVG format for scalability
- Monochrome
- Responsive to light/dark color scheme (regularly black, white for `refers-color-scheme: dark`)

For reference, see the existing images in this folder. If you need help, let us know in the ROOST Discord, or mention it in your pull request description!
